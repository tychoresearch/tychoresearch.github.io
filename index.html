Introducing PolyPerfPolyPerf 简介

Preview预览版

Can a coding agent make a real program faster without changing what it does?编程智能体能否在不改变行为的前提下，让真实程序更快？

PolyPerf is a CPU performance benchmark for coding agents. Each task starts from a real open-source repository just before an upstream performance fix. The agent gets the repository and a description of the slow behaviour, and submits a patch.PolyPerf 是面向编程智能体的 CPU 性能基准。每道题从一个真实的开源仓库出发，停在上游性能修复之前。智能体拿到仓库和慢行为的描述，提交一个补丁。

Tasks题目
44, each taken from a real upstream performance commit44 道，每道取自一次真实的上游性能提交
Languages语言
C, C++, C#, Go, Java, JavaScript, Kotlin, Rust, TypeScript
Score计分
Speedup of the agent’s patch relative to the human fix, timed on hidden workloads智能体补丁相对人类修复的提速，在隐藏工作负载上计时

Preview release: the task set and scores may still change before the paper is out.预览版：论文发表前，题目和分数仍可能调整。
